データ更新

ドロップ表・敵やバウンティの入手先・Riven 相場・日本語名の辞書(Riven性質・シミュレータ用のデータを含む)を取得します。ゲームのアップデート後にも実行してください。


        
取得元: ドロップ表・入手先は WFCD/warframe-drop-data(drops.warframestat.us)、日本語名は calamity-inc/warframe-public-export(取得できなければ公式 Public Export)、Riven 相場は公式の weeklyRivensPC.json(取得できなければ WFCD の api.warframestat.us)です。ロゴ素材が未取得のときは、公式ファンキット(Warframe Fan Kit)の配布元からロゴ素材も取得します。インターネット接続が必要です。

      


/* ---------- データ更新 ---------- */
$("#update-btn").addEventListener("click", async () => {
  const btn = $("#update-btn"), log = $("#update-log");
  btn.disabled = true; btn.textContent = t("upd.fetching"); log.hidden = false; log.textContent = t("upd.fetching.log");
  try {
    // 表示中の言語も送る(日英のほかの言語なら、その言語の名前辞書も取る。ja・en はサーバーが毎回取る)
    const r = await api("/api/update", { method: "POST", body: { lang } });
    showLog(log, r);
    Object.values(dataResets).forEach(reset => reset());
  } catch (e) { log.textContent = e.message; }
  btn.disabled = false; btn.textContent = t("upd.btn"); refreshStatus();
});
loaders.update = () => { applyViewText("update"); return refreshStatus(); };
relabel.update = () => { applyViewText("update"); renderStatus(); relabelLogs(); };
