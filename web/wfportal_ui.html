素材から探す

素材名(日本語・英語・ひらがな)を入力すると、ミッション・敵・バウンティ・レリックなどの入手先と確率を一覧にします。

エリアから探す

惑星またはノード名を選ぶと、出現ステージごとに素材と確率を表示します。

MOD入手一覧

すべての MOD の入手先(ミッション・敵・バウンティ等)をまとめた表です。行をクリックすると入手先の詳細、左端のチェックで所持状況を記録できます。

ゲームの MOD 画面を開いてスクロールしていくと、映った MOD 名を読み取って所持にチェックします(数秒ごと・画面が変わったときだけ)。一致度が低いものは「要確認」に出るので、正しければクリックしてください。読み取りは Windows の文字認識を使います。排他的フルスクリーンでは映らないことがあるので、その場合はボーダーレス(ウィンドウ)表示にするか、スクリーンショットから読み取ってください。

確率: ミッション/バウンティは報酬1回の抽選、敵は1体倒したとき、レリックは開けたときに出る割合です。「記載なし」は公式ドロップ表に無いもの(シンジケート・バロ・ナイトウェーブ・クエスト報酬など)です。

アルケイン所持

公式データ(ExportRelicArcane.json)のアルケインを装備先ごとに一覧にします。左端のチェックで所持として記録し、ランクを選べます(この PC に保存)。名前とレア度はカタカナで表示します(英語名でも絞り込めます)。

種類(装備先)は名前から判定しています(Arcane・Molt・Theorem は Warframe、Magus・Emergence はオペレーター、Virtuos・Eternal はアンプ、Pax・Residual は Kitgun、Exodia は Zaw など)。判定できない新しいアルケインは「その他」に入ります。テクトリストアーティファクト用の Zid-An は、公式データにまだ無いためドロップ表から補います(英語名・レア度なし・最大ランク 5。公式データに入ればそちらを使います)。公式データにあってもゲームに実装されていない 7 件(Arcane Survival・Shield・Defense・Detoxifier・Liquid・Protection・Temperance)は載せません。チェックを外すとランクも消えます。新しいアルケインはゲームのアップデートで増えるので、「データ更新」で取り直してください。

バロ吉入手一覧

Void 商人(Baro Ki'Teer)が今回持ってきた品物と、これまでに持ってきた品物を、自分の所持と照合します。MOD は「MOD入手一覧」の所持、武器は「マスター一覧」のマスター済みで判定し、装飾・外装などはこのページでチェックします(この PC に保存)。

履歴リスト(これまでに持ってきた品物)

履歴リストは、公式データ(「データ更新」で取得)から作る初期リスト(名前が Prisma で始まる武器など・名前が Primed で始まるレジェンダリーの MOD・Primed Chamber)に、この PC で記録したバロの来訪を足したものです。今回の品物は「バロ情報を更新」を押したときだけ公式の World State に問い合わせて取得し、バロが来ていれば来訪を記録します(リストに無い品物は追加し、ある品物は「最後に来た日」「回数」を更新)。過去の日付は分からないため、「最後に来た日」「回数」はこの PC で記録した来訪だけで数えます(TennoCon の来訪は記録しません)。名前が Skin で終わるものは装飾・外装として扱います。消耗品・ブースター・レリックなど何度でも買えるものは照合しません。初期リストから外す Primed MOD・追加する品物は、ツールのフォルダの data/baro_rules.json で変えられます。

Riven相場

公式が毎週公開している PC 版の Riven MOD 取引統計です。単位はプラチナ。


        

        

        
極端な出品価格が混ざるため、平均より中央値が目安になります。件数が少ない武器は振れ幅が大きくなります。

      


      
      

        
Riven性質

        
公式データ(ExportWeapons.json)の性質値を、カテゴリーごとに性質の高い順(●●●●● → ●◯◯◯◯)で並べています。性質が高い武器ほど Riven の効果が大きくなります。

        

        

          
          
        

        

        

        
●の数は性質値で決まります: 0.5〜0.7 ●◯◯◯◯ / 0.71〜0.9 ●●◯◯◯ / 0.91〜1.10 ●●●◯◯ / 1.11〜1.30 ●●●●◯ / 1.31〜1.55 ●●●●●。「性質」の絞り込みは●の数です(●●●◯◯なら 3)。Kitgun はチェンバーごとにプライマリ版とセカンダリ版で値が違います。Zaw はストライクの値です。プライマリのライフル/ショットガンの区分は、Riven 相場のデータがあればその武器種に合わせています。性質値はゲームのアップデートで変わるため、「データ更新」で取り直してください。

      


      
      

        
マスター一覧

        
Warframe・武器・コンパニオンなどのマスター状況です。左端のチェックでマスター済みとして記録します(この PC に保存)。

        

        

          
          
          
          
          
        

        

        

        
Kitgun はチェンバー(プライマリ版とセカンダリ版は別々)、Zaw はストライク、アンプはプリズムと Sirocco の単位で数えます。MOA・ハウンド(組み立て式のロボティック)、アークウイング本体、ネクラメカ、K-ドライブは含みません。マスタリー経験値はランク最大までの値です(Warframe・コンパニオン・センチネルは 1 ランク 200、武器は 100。Kuva・Tenet・Coda などはランク 40)。

      


      
      

        
サイクル

        
昼夜などの切り替えと、デイリー・ウィークリーのリセットまでの時間です。周期から計算するので、通信しなくても表示できます。

        

          
          
        

        

        

        
「公式データで時刻合わせ」は、押したときだけ公式の World State に問い合わせて、平原・ザリマンの切り替わりと PC の時計のずれを合わせます(60 秒以内に押し直したときは前回の結果を使います)。オーブ峡谷・デュヴィリは公式データに手がかりが無いため、基準時刻から計算します。

        

          手動で時刻合わせ(公式データが取れないとき)
          

            
            
            
            
 

          

          

          
ゲーム内で見た残り時間を入れると、以降はそこから計算して表示します。あとで「公式データで時刻合わせ」をすると、公式データの方で上書きします。

シミュレータ

        
フレームの耐久・アビリティ性能、武器のダメージと DPS、Riven の効果の振れ幅を計算します。値はすべて参考値です。

        
      


      
      

        
Tips

        
すぐ見たいメモをまとめるページです。目次と内容は、ツールのフォルダにある tips フォルダのファイルを編集すると変わります(メモ帳・Excel などで編集できます)。

        

          
          
          
        

        

        

          

          

        

        
使えるファイル: .md(見出し・表・箇条書き・チェックボックスなどが使える書き方)/ .txt(そのまま表示)/ .csv(表として表示。Excel で編集可)。ファイル名の先頭の数字(例: 10_)は並び順に使われ、目次には表示されません。tips の中にフォルダを作ると、目次の見出しになります(1段まで)。.md の最初の「# 見出し」が目次の名前になります。

      


      
      

        
データ更新

        
ドロップ表・敵やバウンティの入手先・Riven 相場・日本語名の辞書(Riven性質・シミュレータ用のデータを含む)を取得します。ゲームのアップデート後にも実行してください。

        

        

          

        

        
取得元: ドロップ表・入手先は WFCD/warframe-drop-data(drops.warframestat.us)、日本語名は calamity-inc/warframe-public-export(取得できなければ公式 Public Export)、Riven 相場は公式の weeklyRivensPC.json(取得できなければ WFCD の api.warframestat.us)です。ロゴ素材が未取得のときは、公式ファンキット(Warframe Fan Kit)の配布元からロゴ素材も取得します。インターネット接続が必要です。
