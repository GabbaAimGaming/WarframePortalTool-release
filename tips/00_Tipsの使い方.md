# Tips の使い方

このページは、ツールのフォルダにある **tips** フォルダの中のファイルを表示しています。
ページ上の「新規」「編集」「削除」で直せるほか、ファイルを直接追加・編集・削除しても目次と内容が変わります(直接編集したあとは「再読み込み」を押すか、メニューから Tips を開き直してください)。

## ファイルの置き方

| やりたいこと | 方法 |
|---|---|
| メモを増やす | 「新規」でタイトルと本文を書いて保存する(`.md` になります)。または tips フォルダに `.md` / `.txt` / `.csv` のファイルを置く |
| メモを書き換える | 「編集」(`.md` だけ)。またはファイルを直接編集する |
| 並び順を決める | 目次の ▲▼ で並べ替える(`_order.json` に保存され、ファイル名の数字より優先)。またはファイル名の先頭に数字を付ける(例: `10_日課.md`。数字は目次に表示されません) |
| 目次に見出しを付ける | 「グループ追加」。または tips の中にフォルダを作り、その中にファイルを置く(例: `20_ビルド/Rhino.md`)。1段まで |
| 目次の名前を変える | `.md` の1行目に `# 名前` と書く(無ければファイル名) |
| メモを消す | 「削除」→「ゴミ箱に入れる」(「ゴミ箱」から元に戻せます)か「完全削除する」。またはファイルを削除する |

- 文字コードは UTF-8 がおすすめです(メモ帳の既定)。Excel で保存した CSV(Shift_JIS)も読めます。
- このファイル自体も消したり書き換えたりして構いません。

## .md の書き方(よく使うもの)

```
# 大見出し      ## 中見出し(目次の下に出ます)      ### 小見出し
**太字**   *斜体*   ~~取り消し線~~   ==マーカー==   `コード`
- 箇条書き(先頭に2つ以上の空白で入れ子)
1. 番号付き
- [ ] チェックボックス(未)
- [x] チェックボックス(済)
> 引用
---(横線)
[リンクの文字](https://www.warframe.com/)
[ほかのメモへのリンク](10_日課チェック.md)
![画像の説明](images/画像.png)   ← tips フォルダ内の画像
```

表は `|` で区切ります。2行目の `---` が見出し行の目印です(`:---:` で中央、`---:` で右寄せ)。

```
| 項目 | 内容 |
|---|---:|
| A | 100 |
```

## .csv と .txt

- **.csv**: 1行目が見出しの表として表示します。Excel で作った表を「CSV」で保存して置けばそのまま表になります。
- **.txt**: 書いたとおりにそのまま表示します。
